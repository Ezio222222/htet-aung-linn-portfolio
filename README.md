# Htet Aung Linn — Portfolio

Personal developer portfolio — a dark, futuristic, 3D-interactive site built with React, TypeScript, Vite, Tailwind CSS, and React Three Fiber.

## Tech Stack

- React 19 + TypeScript
- Vite 8 + TanStack Start
- Tailwind CSS v4
- Three.js / React Three Fiber
- Framer Motion
- shadcn/ui

## Development

```sh
git clone https://github.com/Ezio222222/<repo>.git
cd <repo>
npm install
npm run dev
```
